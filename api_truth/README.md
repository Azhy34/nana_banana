# api_truth: источник правды по эндпоинтам

Здесь снимки того, что реально отвечают сервисы. Агент читает их (или ручки посредника `/nodes`, `/kie/models`), а не гадает и не берёт из памяти.

| Что | Файл | Откуда | Как обновить |
|---|---|---|---|
| Ноды ComfyUI вашей установки | `comfy/object_info.json` | `GET /object_info` живого сервера | запустить ComfyUI в Comfy Desktop, затем скрипт |
| Состояние сервера | `comfy/system_stats.json` | `GET /system_stats` | то же |
| Маршруты и сообщения ComfyUI | `comfy_routes.md` | docs.comfy.org (вручную, с датой сверки) | при обновлении ComfyUI перечитать страницы |
| Официальные страницы Comfy и KIE (ноды, API нод, JS-расширения, модели KIE, загрузка файлов, баланс) | `docs/comfy/*.md`, `docs/kie/*.md` | точные адреса `.md` страниц и индексы `llms.txt` (без поиска) | `refresh_api_truth.py --only docs` |
| Схема вызова модели Kie | `kie/<модель>.schema.json` | `GET api.kie.ai/api/v1/models/{model}/schema` | скрипт |
| Цена и надёжность за 24 ч | `kie/catalog_subset.json` | `…/price`, `…/success-rate`, каталог | скрипт; это справка: цена платного вызова читается живой (`reels_pipeline/live_price.py`, нужен ключ) |
| Каталог всех моделей KIE (239 на 05.11) | не сохраняется | `GET api.kie.ai/api/v1/models` (`model`, `taskType`, `pricingDesc`, `provider`) | запросить при выборе новой модели |
| Что и когда сохранено | `MANIFEST.json` | — | скрипт |

Обновить всё (только чтения, кредиты не тратятся):

```
py -3.12 -X utf8 api_truth/refresh_api_truth.py            # всё
py -3.12 -X utf8 api_truth/refresh_api_truth.py --only kie  # только Kie
```

Добавить модель Kie: дописать id в `KIE_MODELS` в скрипте и запустить.

Правила:
- Ключ Kie читается из `.env.local` и нигде не печатается и не сохраняется.
- Если ComfyUI выключен, скрипт честно пишет `offline` и оставляет прошлый снимок.
- Схема Kie главнее наших представлений: перед правкой вызова модели сверяться с `kie/<модель>.schema.json` (какие поля обязательны, какие значения допустимы).
- Kie отвечает `429` при частых запросах; скрипт делает паузы и повторы.
