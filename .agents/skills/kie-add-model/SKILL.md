# KIE: подключить модель и запустить доску (всё через команды, ничего не набирать руками)

Запуск из корня проекта: `py -3.12 -X utf8 <команда>`. Всё ниже бесплатно и только читает, кроме явно помеченного платного.

## Откуда брать информацию (в этом порядке, не из памяти и не из поиска)
1. Схема самой модели у KIE: `scripts/add_model.py <модель>` (поля, лимит промпта, референсы, форматы, размеры, готова ли модель для нас).
2. Цена за картинку по 1K/2K/4K, живая: `scripts/comfy_node_info.py prices [модель ...]`.
3. Что умеет узел и что в нём видно: `scripts/comfy_node_info.py card <Нода>` (блок `kie`); все нужные нам ноды: `card --moonbloom`.
4. Точный id модели: `GET https://api.kie.ai/api/v1/models` (в `prices` есть список наблюдаемых).

## Подключить модель
```
scripts/add_model.py <модель>                       # отчёт: READY / BLOCKER / warning; снимок схемы в api_truth/kie
scripts/add_model.py <модель> --write --tag <тег>   # только если READY: 3 строки реестра + тесты
scripts/run_board.py photos --reload                # новый узел появился в окне; сухой прогон
```
BLOCKER = не подключаем: нет референсов, видео-модель, обязательное поле, которого фабрика узлов не знает (`quality`), нет 2K, лимит промпта меньше brief. Warning = подключаем, но знаем: нет формата 4:3, нет поля размера (пиксели смотреть после прогона), полный промпт не влезает (только `prompt_mode=brief`).

После `--write`: модель в `specs/active_board.json` записью `{"id", "model", "prompt": "full|brief"}` (макс. 3 цепочки), затем `scripts/build_comfy_workflows.py --verify-live`.

**Подключение новой модели = приёмка один раз** («Tests policy» в `CLAUDE.md`): отчёт `add_model.py`, тесты области (`scripts/test_policy.py --new --run`), сухой прогон, один платный пробный кадр по «да». После приёмки модель работает как остальные: **тесты при обычных запусках доски не гоняются**, проверка запуска это сухой прогон.

## Запустить доску
```
scripts/run_board.py photos                          # бесплатно: dry run, живая цена, проверка запроса, баланс
scripts/run_board.py photos --paid all               # печатает живую котировку, НИЧЕГО не запускает
scripts/run_board.py photos --paid all --confirm N   # платно, только если N равно котировке
scripts/run_board.py video                           # Kling стартует как dry run
```
Результат: таблица (модель, кредиты, пиксели, время, файл) и контактный лист во временной папке. `--reload` после правки кода узлов (иначе ComfyUI держит старые объекты узлов).

## Жёсткие правила
- Платный запуск только по «да» владельца с числом кредитов (число из `--paid ... ` без `--confirm`). Сначала dry run.
- 2K минимум. Каждый платный кадр = годный рекламный креатив: разные дизайны, а не один на разных моделях.
- Роспись это продукт: приходит только референсом; промпт описывает дизайн, не роспись. Правило «как роспись сидит на стене» лежит в спеке листинга (`brief`), не в коде.
- Запуск ComfyUI и перезапуск делает владелец. Ключи только из `.env.local`, не выводить. Один открытый ComfyUI-окно.

## Если что-то не так
- «unexpected keyword argument» после правки: `run_board.py ... --reload`.
- Узел упал на KIE (`[500]`): за него не списали, но он остановил всю доску; повтор той же командой (готовые кадры берутся с диска, `reuse_existing`).
- Остальное, ловушки, устройство моста, цены, формат досок: `.agents/skills/comfy-pipeline/SKILL.md`, подробности в `reference.md` рядом (читать по необходимости, не целиком).
